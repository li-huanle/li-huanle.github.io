## 为什么做这个

广告主预算在收缩，把所有筹码压在"服务客户"上的反脆弱性不够。需要做一条不依赖客户单子的副业管道。

video10x 是这条管道的第一个候选 —— 用我已有的素材测试、内容拆解、AI 工作流经验，把"视频脚本 → 素材 → 多平台发布"做成一个海外 SaaS。

## 已经摸到的

- 技术选型：用第三方视频生成 API 拼装而不是自研模型（成本可控，迭代快）
- 商业模式：订阅制，参考海外同类产品的定价区间
- 用户画像：海外中小独立创作者 + 跨境电商内容团队

## 当前卡点

**1. 支付链路**

接入 Creem 遇到问题，海外支付不像国内那么"接入就能用"，KYC、税务、退款政策都要逐一过。

**2. 获客通道**

海外 SaaS 的获客和国内打法不一样，依赖产品 hunt / Reddit / Twitter 的内容种草，需要重建一套话术和节奏。
