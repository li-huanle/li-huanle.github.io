## 解决什么问题

很多日报有数据、没有决策：昨天花了多少、点击多少、成本多少，但没有回答为什么变、接下来改什么、什么时候判断有效。

这套闭环把分析压成四步：

```text
数据（发生了什么）
→ 洞察（变化来自哪里）
→ 行动（下一步改变什么）
→ 结果（动作是否有效）
→ 更新基线与规则
```

## 第一步：锁定事实

先确认最新数据源、时间窗口、归因口径和核心 KPI。前链路只有曝光、点击、互动或 A3 时，不跨级写成交改善；后链路缺失则明确标注“未回传 / 待补”。

建议保留一张口径表：

| 项目 | 必须写清 |
|---|---|
| 时间 | 自然日、累计期、完整周还是阶段快照 |
| 对象 | 平台、账户、产品线、达人、素材或关键词 |
| 指标 | 定义、分母、归因窗口、数据源 |
| 状态 | 已回传、待补、估算或不可比 |

## 第二步：把波动拆到可行动层

不要停在“成本上涨”。依次向下拆：

1. 渠道与点位：搜索、信息流、全站、再营销谁在贡献变化？
2. 内容：哪些素材高消耗低回流，哪些内容具备稳定放量能力？
3. 人群：扩量是否带来意图稀释？新老客、人群包是否混算？
4. 关键词：品牌词、品类词、场景词和痛点长尾词分别承担什么角色？
5. 承接：点击后是否在落地页、店铺、私信或成交环节流失？

每条洞察至少包含“证据 + 机制解释 + 不确定性”。相关不等于因果；缺少对照时，用“可能”“待验证”，不用确定语气。

## 第三步：把建议写成实验

一条可执行动作应包含：

```text
对象 + 改动变量 + 负责人 + 观察周期 + 成功指标 + 停止条件
```

例如，不写“优化素材”，写“本周将高消耗低回流素材降权，保留两个稳定素材作对照；观察 3 天，若核心成本改善且量级不低于基线，再扩大替换比例”。

一次只改变少数变量。账户结构、预算、素材和人群同时大改，即使数据变好也无法知道什么有效。

## 第四步：回读结果并沉淀

观察窗结束后回答四个问题：

- 结果是否达到预设指标？
- 变化是否可能由节假日、竞价、库存或回传延迟造成？
- 这次规则能否迁移到其他产品、平台或阶段？
- 哪些判断应写回模板、SOP、看板或自动化？

沉淀的不是一组历史数字，而是“在什么条件下，什么动作更可能有效”。

## 边界

- 平台口径、模型版本和后台数据会变化，复用前必须重新核验。
- 小样本、短观察窗和回传延迟都会制造假改善。
- 对外报告只公开脱敏方法与聚合结论，不公开客户身份、原始明细和可反推的业务数字。
