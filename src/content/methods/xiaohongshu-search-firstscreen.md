## 一句话

小红书搜索首屏是"心智占位 + 高 CTR/CVR + 仅高相关内容参竞"的稀缺位，**先把"相关性=好"打到入场券档，再谈拓词和出价**——否则花再多预算也进不了首屏池。

## 首屏位置（先讲清楚）

| 位置 | 自然排序位 |
|---|---|
| 首屏（首位）推广位 | 第 2 或第 3 位（左上 / 右下，不同时出现） |
| 第二推广位 | 第 9–16 位间浮动 |
| 第三推广位 | 第 16–29 位间浮动 |

进入首屏池的两个硬条件：相关性 = 好；eCPM 高 + 有社区价值。

## 三要素

### A. 买好词

按"决策成本 → 产出确定性"排序的拓词工具：

- 客户刚起量 / 没词库 → 智能拓词 + 推荐词包做基线
- 客户跑了一段时间有数据 → 高潜词包 + 上下游 + 用户路径拓词做精拓
- 做客资收集营销目的 → 优先用 new 高潜词包（差异化能力）

### B. 说对话（相关性 = 好）

三段闭环：

| 环节 | 动作 | 产品 |
|---|---|---|
| 投前校准 | 计划搭建前预检词-笔记匹配 | 投前-相关性预检 |
| 投中诊断 | 实时修正偏差，补高相关笔记 | 投中-相关性诊断 |
| 投后反哺 | 找"高需求 - 首屏低覆盖"机会词缺口 | 投后-首屏机会词优化 |

**对客话术**：首屏池本来就是高相关笔记之间的竞争，相关性差的笔记不是出价高就能进，是连参竞资格都没有。我们先把笔记打到"好"档，再讨论怎么放量。

### C. 出好价

eCPM 公式底层：`eCPM = 转化出价 × CTR × CVR × 1000`

- A 决定能不能被触发
- B 决定 CTR / CVR 上限
- C 是在前两者上限内的价格竞争

A、B 不达标时光靠加价进不了首屏。

## 对客 4 句速记

1. 首屏 = 第一眼经济 = 心智占位
2. 首屏 CTR 是后置坑位的 2 倍以上
3. 首屏对比后置，表单 CVR / 私信 CVR 高 1-1.5 倍
4. 首屏池只让高相关内容竞争，相关性差的连入场资格都没有

## 风险边界

- 这是优质代理 / 自运营账户口径，普通代理不适用
- 平台给的 CTR/CVR 倍数是宣传，落地必须用自有账户数据校验
- "new 高潜词包" 目前只支持客资收集营销目的
