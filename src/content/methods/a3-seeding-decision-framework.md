## 解决什么问题

客户常问："我到底要不要种草？种草预算给多少合理？"

凭品类经验拍脑袋的答案站不住，需要一套可量化的判断标准。

## 使用前提

- 你能拿到品牌方的人群资产（巨量云图 / 千瓜 / 灵犀都行）
- 知道当前 A3 人群规模、A3→A5 转化率、品类自然渗透率基线
- 至少有 1 个月的历史数据做基线

## 6 切面拆解

| 切面 | 判断点 |
|---|---|
| 解决什么问题 | 在"要不要种草"和"种草投多少"之间做客观判断 |
| 使用前提 | 有人群资产、有 A3→A5 转化率、有历史基线 |
| 操作步骤 | 拉 A3 池规模 → 算 A3→A5 自然转化 → 对比品类基线 → 测算缺口预算 |
| 判断标准 | 推进：A3 规模 < 品类基线 50% / 停止：A3→A5 转化率已 ≥ 行业 TOP10% |
| 常见错误 | 把曝光当种草、把点赞当 A3、不区分新老客 |
| 风险边界 | A3 定义随平台口径变化，每 3 个月校准一次 |

## 操作步骤

1. **拉 A3 池规模**（巨量云图 / 灵犀都可，注意 90 天滚动口径）
2. **算 A3 → A5 自然转化率**（不投种草情况下的基线）
3. **对比品类渗透基线**：A3 池规模 / 品类总目标人群
4. **测算种草预算缺口**：
   - 缺口 = 目标 A3 池规模 - 当前 A3 池规模
   - 单位 A3 成本 = 历史种草消耗 / 历史 A3 增量
   - 建议预算 = 缺口 × 单位成本 × 1.2（安全冗余）

## 推进 / 停止判断

**推进条件**：
- A3 池规模 < 品类基线 50%
- A3 → A5 转化率仍有提升空间（< 行业 TOP30%）
- 单位 A3 成本 < 客单价 × 30%

**停止条件**：
- A3 → A5 转化率 ≥ 行业 TOP10%（继续种草边际收益低）
- 单位 A3 成本 > 客单价 × 50%
- A3 池已饱和（接近品类总目标人群）

## 常见错误

- **把曝光当种草**：曝光只是触达，A3 才是有兴趣行为的人群
- **把点赞当 A3**：点赞行为权重低，A3 包含搜索、收藏、加购等高权重行为
- **不区分新老客**：种草的 ROI 应只算新客 A3 增量
