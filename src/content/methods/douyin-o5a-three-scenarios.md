## 先说结论

O-5A 的价值不是多一套人群术语，而是让团队从生意结果倒推人群资产，再把人群任务翻译成内容和媒介动作。品牌建设、新品上市和节点大促的目标不同，但都可以用同一条链路对齐：

```text
生意目标
→ 需要新增或推动哪一层人群
→ 内容要改变什么认知或行为
→ 哪些媒介触点负责扩量、种草和转化
→ 用人群流转与生意结果共同复盘
```

## O-5A 各自承担什么任务

| 人群阶段 | 主要任务 | 常见观察方向 |
|---|---|---|
| O 机会人群 | 找到值得覆盖但尚未建立关系的人 | 人群规模、品类兴趣、触达覆盖 |
| A1 / A2 认知兴趣 | 建立品牌与需求场景的连接 | 有效触达、内容互动、品牌认知 |
| A3 深度种草 | 形成更明确的商品或品牌意向 | 新增 A3、搜索、进店、深度互动 |
| A4 购买 | 推动首次成交或节点转化 | 成交人数、转化率、获客成本 |
| A5 复购 | 提高复购、会员和长期价值 | 复购率、会员贡献、用户价值 |

不同平台对阶段和指标的定义可能不同。做方案时要先写清数据入口和口径，不能把“互动过”直接等同于“已经被种草”。

## 三个常见营销场景

### 1. 品牌力提升

适用于已经有一定市场基础，但品牌规模、效率或心智存在短板的品牌。

1. 先诊断问题在知名度、偏好、购买意愿还是品牌联想。
2. 对比目标人群与已渗透人群，找出“应该认识但还没认识品牌”的人。
3. 根据人群内容偏好确定说什么、由谁说、在哪个触点放大。
4. 复盘品牌指标时，同时看规模和效率，避免只用曝光证明品牌增长。

### 2. 新品上市

新品不是直接进入放量，而是依次回答四个问题：

| 阶段 | 关键问题 | 核心动作 |
|---|---|---|
| 企划 | 产品为谁解决什么问题 | 赛道、机会人群、卖点与价格带判断 |
| 测试 | 哪组卖点和内容真正有效 | 小规模素材、人群与承接测试 |
| 种草 | 如何积累认知与深度兴趣 | 达人内容、信息流、搜索激发与承接 |
| 爆发 | 哪些人群和内容值得集中预算 | 短视频、直播、搜索与商品协同 |

### 3. 大促增长

大促预算不要只按历史消耗同比增加。更稳的拆法是：

```text
GMV 目标
→ 新客 / 老客与客单假设
→ 需要多少可转化人群
→ 大促前要积累多少 A2 / A3
→ 分配扩量、种草、搜索和转化触点
```

这个过程必须写明转化率、客单价和归因窗口假设。缺少这些前提时，预算只能称为情景测算，不能称为确定性预测。

## 一张可执行的规划表

每个项目至少明确以下字段：

| 字段 | 要回答的问题 |
|---|---|
| 生意目标 | 最终希望改变什么经营结果 |
| 核心人群阶段 | 当前主要缺 O、A1/A2、A3 还是 A4/A5 |
| 内容任务 | 建认知、讲卖点、处理异议还是促转化 |
| 媒介任务 | 哪些触点负责扩量、种草、搜索和收口 |
| 领先指标 | 在成交出现前，用什么判断方向是否有效 |
| 结果指标 | 最终按什么口径验收 |
| 观察窗口 | 多久判断一次，归因延迟如何处理 |

## 常见误用

- 把 O-5A 当成定向包清单，而不是经营过程。
- 只报告 A3 数量，不看 A3 成本、流转和后链路承接。
- 用平台人群资产替代真实成交与利润。
- 新品尚未完成卖点测试，就直接进入大规模投放。
- 大促只拆媒介预算，没有从 GMV 和人群蓄水需求反推。
