## 解决什么问题

竞品直播话术分析过去要么靠人工记笔记（信息丢失严重），要么靠转录全文（信息冗余看不出重点）。需要一个能把话术抽成结构化、可对比、可复用的工作流。

来源：郑镇涛实战版。

## 5 步漏斗式提问

```
转录原文 → Step1: 开场吸引 → Step2: 痛点放大 → Step3: 价值塑造
        → Step4: 信任建立 → Step5: 逼单转化
```

每一步问 AI 同一组问题：

1. 主播说了什么（具体话术 + 时间戳）
2. 用了什么手法（情绪 / 数字 / 故事 / 权威 / 稀缺 / 对比）
3. 这步的目的是什么（吸引注意 / 唤起焦虑 / 建立差异 / 解除疑虑 / 制造紧迫）

## 输出格式

```markdown
## 竞品 X 直播话术诊断

| 步骤 | 主播话术 | 手法 | 时长占比 |
|---|---|---|---|
| 开场 | "今天给大家带来..." | 数字 + 权威 | 8% |
| 痛点 | "你是不是经常..." | 情绪 + 对比 | 22% |
| ... |

## 5 维度差异化定位建议

| 维度 | 竞品做法 | 我方建议 |
|---|---|---|
| 开场钩子 | 数字权威 | 故事 + 反预期 |
| ...
```

## 使用前提

- 直播录屏 / 转录文本可获取
- AI 模型有足够上下文容纳完整话术（建议 Qwen3 / DeepSeek / GPT-4o）
- 已经先做过基础品牌定位分析，否则差异化建议会空泛

## 推进 / 停止判断

**推进**：竞品直播间稳定开播、话术成熟、有清晰段落结构
**停止**：竞品直播间还在测试阶段（话术每场都换），分析没参考价值

## 常见错误

- 直接喂全文转录给 AI：上下文挤爆 + 重点丢失
- 不带时间戳：复盘时无法对照视频
- 只看自家想看的（比如"卖点"），漏掉信任 / 逼单这两步真正的差异

## 风险边界

- AI 摘要不能替代真人复看，关键节点必须回看视频
- 话术分析有版权风险，仅用于内部策略，不外传 / 不公开发布
- 5 步框架适合标品直播，礼品 / 知识付费 / 服务类直播需调整段落定义
