## 解决什么问题

很多新品方案先写一个漂亮主题，再补达人、信息流和搜索。问题是主题好听，但执行时不知道先打谁、买什么词、内容怎么分层、预算怎么推进。

更稳的做法是先确认"谁在搜、搜什么、为什么焦虑、信谁、看什么内容"，再倒推出 KFS 和预算节奏。

## 总框架

```text
Brief Recap
-> 基础人货场
-> 小红书人群洞察
-> 搜索路径与关键词分层
-> 高热内容与评论洞察
-> 人货场转译表
-> 策略主题
-> KFS 策略
-> Roadmap 与效果预估
-> 合规注意事项
```

## Brief Recap

先用一句话把项目压缩成可执行目标：

```text
强绑定 [核心高意图人群]，打造 [品类/场景心智]，在 [核心周期] 内完成 [市场动作]
```

这句话必须回答三个问题：谁是核心高意图人群、要抢占什么心智、周期内要完成什么动作。

## 人货场转译

不要把客户资料原样搬进方案，要翻译成小红书可执行语言。

| 层级 | 要回答的问题 | 输出形态 |
|---|---|---|
| 人 | 目标用户是谁，处在哪个问题阶段 | 人群画像、人群包定义、人群量级 |
| 货 | 产品解决什么痛点，如何转译成用户收益 | 卖点-痛点-话术转译 |
| 场 | 用户在哪些时刻搜索、决策、焦虑 | 搜索场景、内容场景、转化场景 |

## 反漏斗搜索拆解

小红书搜索可以按"反漏斗模型"拆：

```text
从核心搜索词反推用户焦虑
-> 拆出上游词 / 核心词 / 下游词
-> 用下游痛点词做高意图渗透
-> 用上游泛词做规模扩展
```

优先级建议：

```text
先打下游高意图痛点词
-> 再打核心品类词
-> 最后用上游泛词扩量
```

## KFS 三位一体

KFS 不是三段散写，而是同一人群分层下的同步策略。

| 人群分层 | K：内容策略 | F：人群策略 | S：搜索策略 |
|---|---|---|---|
| 核心问题人群 | 专家注意事项、KOC 真实分享、KOL 经验攻略 | 深度搜索和深度观看人群 | 高频痛点长尾词、禁忌词、攻略词 |
| 次核心准备人群 | 专家分享、长篇经验、前置教育 | 浅度搜索和内容观看人群 | 前置词、对比词、怎么用、怎么选 |

关键是避免内容讲 A 人群、投流打 B 人群、搜索买 C 词。

## Roadmap 与预算节奏

| 阶段 | 预算策略 | KFS 权重 | 核心目标 |
|---|---|---|---|
| 新品打爆期 | 前置重投 | 重 K，KOL / KOC 全量测试 | 快速测试内容、口感、卖点、人群 |
| 日常种草期 | 控量优化 | 重 K + 重 F | 延续优质内容和人群包 |
| 大促活动期 | 转化加重 | 重 K + 重 S + 重 CID | 高意图收割、站内外转化 |
| 长效转化期 | 低预算维护 | KFS 均衡 | 依赖已沉淀人群资产维持转化 |

## 风险边界

- 健康、保健品、营养补充类方案必须前置合规检查，避免制造恐慌、效果承诺、医疗化表达和专利功效夸大。
- KFS 框架可复用，但具体人群包、搜索词、出价、预算和效果预估必须按当次后台数据重算。
- Roadmap 不应只写阶段名，必须同步给阶段预算、K/F/S/CID 拆分、效果预估指标和备注说明。
