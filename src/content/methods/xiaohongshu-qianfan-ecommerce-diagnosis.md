## 先说结论

闭环电商投放出现“不起量、ROI 不稳、搜索跑不出”时，问题往往不只在出价。更有效的检查顺序是：先确认主体和目标，再看流量结构、人群、素材，最后检查商品页、直播间与服务承接。

```text
推广主体
→ 优化目标
→ 通投 / 搜索流量结构
→ 人群输入
→ 素材效率
→ 商品或直播承接
```

## 1. 先分清推广主体

| 经营场景 | 主要承接对象 | 优先解决的问题 |
|---|---|---|
| 日常商品成交 | 商品与笔记 | 稳定成交与长期 ROI |
| 直播间即时转化 | 直播间与直播商品 | 进房、商品点击、支付漏斗 |
| 新品或新品牌蓄水 | 内容笔记 | 测卖点、积累兴趣与搜索 |
| 高意向需求收口 | 搜索结果与商品 | 关键词相关性和转化承接 |

如果主体都没分清，就容易用浅层内容指标要求成交，或用成交目标强行评价尚在测试期的新品内容。

## 2. 目标和阶段要匹配

深层成交目标适合已经具备商品、价格和页面承接能力的账户；浅层点击或观播更适合测试内容和积累信号。选择目标前要问：

- 当前最想改变的是成交、访客、观播还是内容互动？
- 账户是否已经积累足够的转化数据？
- 商品页、直播间和客服能否承接新增流量？
- 本轮是探索、稳定还是放量阶段？

不要同时用低成本、最大消耗和高 ROI 三个互相冲突的目标验收同一计划。

## 3. 通投与搜索如何分工

- **通投**负责发现更广的人群和素材组合，是规模基础。
- **搜索**承接用户主动表达的需求，适合高意向词、防守词和场景词。
- 二者比例不应套固定答案，应由搜索需求量、关键词覆盖、素材相关性和转化效率决定。

搜索不出量时，先检查搜索词、买词、笔记标题正文、首图表达和商品承接是否一致，再考虑扩词或出价。相关性不足时，单纯加价只能买来更贵的低质量流量。

## 4. 人群不是越窄越精准

至少保留三类测试：

1. 智能或相对宽的人群作为基线。
2. 品牌行为、行业兴趣、电商行为等高级定向，验证差异化输入。
3. 已有高价值人群的扩展或排除测试。

高级定向规模太小，会导致系统缺少探索空间。判断人群是否有效时，应同时看消耗能力、点击、成交和增量，而不是只看画像是否“像目标客户”。

## 5. 素材按漏斗分诊

| 信号 | 可能问题 | 优先动作 |
|---|---|---|
| 曝光有、点击低 | 封面、标题或首屏没有击中需求 | 重做首屏与标题，按人群拆表达 |
| 点击有、行动弱 | 卖点、节奏或利益表达不足 | 调整结构、证据和行动理由 |
| 进店有、成交低 | 价格、详情页、客服或服务政策不匹配 | 先修承接，再扩大流量 |
| 前期有效、随后衰退 | 素材疲劳或重复触达 | 衍生新素材，关闭低效重复计划 |

## 6. 五层排障顺序

1. **店铺层**：GMV、自然与广告关系、商品承接。
2. **账户层**：预算、余额、消耗节奏、账户间抢量。
3. **计划层**：目标、预算、出价、学习状态和托管方式。
4. **素材层**：点击、行动、成交和内容角度差异。
5. **关键词 / 人群层**：哪些搜索词和人群真正贡献增量。

直播场景还要补一层完整漏斗：曝光 → 进房 → 停留 → 商品点击 → 下单 → 支付。只看直播间 ROI，会掩盖到底是流量、内容还是商品出了问题。

## 常见错误

- 计划不起量就连续提高出价，却不检查素材和承接。
- 新账户只增加计划数量，不增加素材和策略差异。
- 多账户用相同素材推广同一商品，造成内部竞争。
- 把托管理解为无需运营，未提供足够素材和转化环境。
- 搜索买了大量词，但内容与商品没有回答这些搜索需求。
